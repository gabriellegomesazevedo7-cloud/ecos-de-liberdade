# Ecos de Liberdade — Combate à Violência contra a Mulher

## Sobre o projeto

O **Ecos de Liberdade** é um portal web desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso Técnico em Informática para Internet da ETEC de Rio Grande da Serra, em 2025.

O projeto tem como objetivo combater a violência contra a mulher por meio da conscientização, da divulgação de informações e da facilitação do acesso a canais de denúncia e redes de apoio.

## Funcionalidades

- Informações sobre os tipos de violência contra a mulher e a legislação relacionada.
- Divulgação de canais de denúncia e serviços de apoio.
- Busca por delegacias, centros de atendimento psicológico e assistência jurídica.
- Conteúdos sobre defesa pessoal e histórias de mulheres importantes.
- Compartilhamento de relatos, com opção de anonimato.
- Cadastro e login de usuários.
- Informações sobre doações e voluntariado.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Figma

## Identidade visual

O projeto utiliza tons de roxo e lilás para representar conscientização, força e acolhimento. Sua mascote, Liberty, simboliza a luta pela liberdade e pela proteção das mulheres.

## Observação

Este repositório apresenta o projeto desenvolvido para fins acadêmicos e de portfólio. Como o sistema utiliza PHP e MySQL, sua execução completa exige um ambiente de hospedagem compatível com essas tecnologias. O GitHub Pages, sozinho, não executa PHP nem disponibiliza um banco de dados MySQL.
